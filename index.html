About

A bit about me.

I'm an Application Security Engineer with 4 years of experience. My work spans pentesting, vulnerability research, and building security tools used by researchers worldwide. Day-to-day I handle secure code review, building security into CI/CD, and working with dev teams to fix vulnerabilities before they hit production.

I specialize in API security, web and mobile application pentesting, and breaking systems to understand how to build them stronger. Lately I've been focused on AI security - prompt injection, model manipulation, and building security integrations for AI-powered systems. I also build open-source tools when I can't find exactly what I need for a job.
